# Seed Tamil lexicon — cascade Tier 1 (plan §9, Phase 1).
#
# One word per line. `#` starts a comment. NFC-normalized on load.
#
# SCOPE WARNING: this is a SEED, sized to make the engine testable end to end.
# It is nowhere near production coverage. Tier 1 flags any word absent from this
# file, so shipping it as-is would produce false positives on every ordinary word
# it happens not to contain. Production coverage comes from a corpus build
# (Wikipedia + the accepted-correction event log) — see plan §11.
#
# Note the deliberate presence of BOTH members of confusable pairs below
# (புலி/புளி, வலி/வளி/வழி, பள்ளி/பல்லி). Each is a real Tamil word. Because
# Tier 1 only ever flags out-of-vocabulary words, their presence here is what
# stops the engine "correcting" tiger into tamarind.
